# STM32_1 실행 안내

[전체 프로젝트](project/)의 ece2_474.code-workspace를 VS Code에서 엽니다. ARM GCC·CMake·Ninja를 PATH에 두거나 STM32 확장 도구를 설정합니다.

stm32_1_config.h: 1=버튼 IRQ, 2=TIM6 LED, 3=50% PWM, 4=과제3, 5=과제4. 저장·Build·F5 다운로드 후 실행합니다.

PC13 버튼 / PA5 내장 LED / PB4 TIM3 CH1 PWM. TIM6 100ms, 버튼 입력 잠금 200ms. 모드4 첫 간격은 TIM6 위상 때문에 최대 100ms 짧을 수 있습니다. 상태 변경 간격 1/2/4/8초의 전체 ON+OFF 주기는 2/4/8/16초입니다.

모드5 디버거: button_isr_p7의 PWM 변경 줄에 F9, F5로 실행, Watch에서 g_pwm_step·g_pwm_ccr·htim3.Instance->CCR1 확인, F10으로 진행. CCR은 250/500/750입니다. PWM 파형은 중단점을 해제한 정상 실행에서 측정합니다. 예상 HIGH 250/500/750us, 주기 1ms.

실제 다운로드·측정·관측 여부는 제출 현황표를 확인합니다. 과거 PASS 로그를 실측으로 표시하지 않습니다.
