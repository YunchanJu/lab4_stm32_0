# 실제 연결 전 확인

교안에는 XDC가 없다고 명시되어 있습니다. 이 프로젝트는 현재 클록 20ns만 제약하여 시뮬레이션·합성 검증용으로 준비했습니다.
보드 커넥터와 주변 장치 핀을 확인하기 전에는 비트스트림 생성을 완료했다고 표시하지 않습니다. sample/data_valid는 내부 관측 신호로 둘지, 외부 핀으로 출력할지도 결정해야 합니다.

| 포트 | 보드 핀/방향·극성 |
|---|---|
| clk_50mhz | 실험실 확인 필요 |
| rst_p | 실험실 확인 필요 |
| add_sel[2:0] | 실험실 확인 필요 |
| adc_sclk | 실험실 확인 필요 |
| adc_ncs | 실험실 확인 필요 |
