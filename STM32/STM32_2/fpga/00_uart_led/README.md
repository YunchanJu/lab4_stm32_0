# UART 수신과 LED 명령 제어

2026-10-26에 교안 과제6·7을 위해 작성한 준비 코드입니다. 50MHz에서 CLKS_PER_BIT=5208이면 약 9600.61 baud입니다. 입력은 2단 동기화하고 start·8개 LSB-first 데이터·stop을 검사합니다.

수신 문자 '0'은 LED 끄기, '1'은 켜기, '2'는 토글, 기타는 유지합니다. 받은 바이트를 FPGA TX로 그대로 출력합니다. 출력 버퍼가 넘치면 overrun이 유지되며 잘못된 stop 비트는 framing_error 펄스로 알립니다. 재설정으로 초기화합니다.

테스트벤치는 반복 켜기/토글, 일반 문자, 숫자 0x01과 문자 0x31 구분 및 에코를 검사합니다. 물리 핀은 장비 핀맵으로 확인해야 합니다. STM32 PC10은 FPGA 확장 RX로 연결하고 GND를 공통으로 합니다. FPGA TX의 PC 출력과 MCU 응답은 서로 다른 연결입니다.

실제 장비 다운로드·UART 전송 성공은 아직 측정하지 않았습니다.
