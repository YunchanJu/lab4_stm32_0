# 10/12 보완 자료

주윤찬 · 2023440132

1→2→4→8→1초 과제는 STM32 과제1(내장 PA5)·과제2(외부 PB0 또는 PB1)입니다. Vivado 대상은 별도 추가실험 4비트 곱셈기와 BCD 변환기입니다.

- stm32_project: 전체 C 프로젝트. Core/Inc/stm32_0_config.h에서 STAGE3=내장, STAGE4=외부를 선택·저장하고 재빌드·다운로드합니다.
- firmware/stage3.elf 및 .hex: 내장 LED 과제1. stage4: 외부 LED 과제2(PB0).
- 외부 LED: PB0 → 저항330Ω~1kΩ → LED 양극, 음극 → GND.
- fpga: 기존 실험의 RTL·TB·핀 설정. 공개 README/첨부 영상과 원본 사진은 기존 저장소 루트에 보관됩니다.
- verification: 보관된 ARM 빌드 로그·HEX 검증 해시. 촬영 당시 바이너리와 일치한다는 증거는 없으므로 과거 영상의 정확한 실행 바이너리로 단정하지 않습니다.

기존 결과레포트와 실험 영상은 변경하지 않습니다. 이번 보완은 소스 접근성과 재현 자료를 보충하는 작업입니다.
