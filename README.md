# STM32 실험 자료

10/12~11/2 실험을 주차·실험별로 정리했습니다. 원본 실험 영상과 보고서는 보존하고 전체 빌드 소스를 펼쳐 놓았습니다.

| 날짜 | 폴더 | 내용 | 확인 상태 |
|---|---|---|---|
| 10/12 | [STM32_0](STM32/STM32_0/) | LED·버튼 폴링, 곱셈기·BCD | 결과보고서·영상 4개 보관 |
| 10/19 | [STM32_1](STM32/STM32_1/) | 인터럽트·PWM, 피아노·신호등·ADC | 코드·시연 영상 5개·사진 19장·PWM 실측 보관 |
| 10/26 | [STM32_2](STM32/STM32_2/) | UART, 서보·SRAM·DAC | 준비 코드·ARM 빌드·Vivado GUI 검증 완료 |
| 11/2 | [STM32_3](STM32/STM32_3/) | SPI 통신 | 제출 안내 폴더 |

- [날짜별 제출 항목·현재 현황](STM32/SUBMISSION_CHECKLIST.md)

검증 로그의 PASS는 빌드·시뮬레이션 범위입니다. 실측과 실제 보드 시연의 증거로 대신하지 않습니다. 새로 복원한 코드가 과거 촬영 시점의 바이너리와 동일하다고 단정하지 않습니다.
